# プロジェクトの設計 — モデルが何を対象にしているか

出典: iGEM Keio × iGEM Waseda 合同ミートアップ資料「One Direction」
（Keio-Japan 2026）。本モデルはこの設計を対象とする。

## 大目標

多細胞システムに**「方向」を設計対象として追加する**。

自然界の方向性のある多細胞（上皮の一方通行の吸収・分泌、神経の方向性のある情報伝達）
に対し、既存の合成細胞接着技術（Glass & Riedel-Kruse 2018）は特異的な接着と
パターン形成はできるが、**細胞の方向は設計対象になっていない**。そこを埋める。

## 接着機構 — ペリプラズムでの係留

**核心は、外膜の Intimin を、内膜側の極マーカーへペリプラズム越しに係留すること。**

```
菌体外        Ag / Nb            ← 細胞間接着はここで起きる
              │ Spacer
  外膜        Intimin β-barrel
              │ CoilE            ← LysM を置換して付与
ペリプラズム    ‖ CoilR ‖ CoilE    ← ここで結合
              │ CoilR
  内膜        TM
              │ msfGFP
 細胞質       H3H4 ─── PopZ      ← 極局在の起点
```

構成要素：

| 部品 | 役割 |
|---|---|
| PopZ | 細胞質の極マーカー。極を定義する |
| H3H4 | PopZ 結合ドメイン。内膜アダプターを極へ連れて行く |
| TM + CoilR | 内膜に固定し、ペリプラズムへ CoilR を提示する |
| Intimin + CoilE | 外膜アドヘシン。ペリプラズム側に CoilE を持つ |
| Ag / Nb | Intimin の passenger。菌体外で細胞間接着を担う |
| DivIVA | 反対極を規定する第2の極マーカー |

**この設計の要点は、外膜タンパクを極へ留める「留め具」をペリプラズムのコイルドコイルで
作っていることにある。** PopZ も DivIVA も細胞質・内膜側の因子なので、そのままでは
外膜タンパクに届かない。CoilR–CoilE がその隔たりを橋渡しする。
先行研究は Lim & Bernhardt (2019) の POLAR 系。

## 方向はどこから来るか

**2つの極に別々の分子を置くことによる。**

- 片極に **PopZ**（実験①で単極になる発現条件を選ぶ。Lin 2021 によれば発現量を
  上げると単極から両極へ切り替わるので、**単極側を選ぶ**）
- 反対極に **DivIVA**（実験③。PopZ に分解機能や膜認識阻害を付けて第2極を作る）
- それぞれの極に **Ag と Nb** を分けて提示する

Ag 極は Nb 極としか結合できないので、細胞は**頭-尾**で連なる。これが「方向」である。

## 本モデルとの対応

資料の「Dry と Wet の連携方針②」が本モデルの担当範囲にあたる。

> **1. 発現量から Intimin の局在パターン予測**
> プロモーター強度や発現量を変えたとき、Intimin が極に何分子程度集まり、
> 細胞側面にどの程度残るのか。
>
> **2. 局在パターンから細胞間の結合様式予測**
> Intimin の数や局在の仕方によって、**細胞がどの向きで結合するか**、
> あるいは結合しないか。

本モデルは主に **2** に答える。1 については、本モデルは分布を入力として受け取る
（`f_pole`, `tip_width_um`, `polar_split`）ので、係留機構から分布を導く部分は
別に必要である。

### 非対称二極をどう扱うか

本モデルの `polar_split` は「1種類のアドヘシンを両極にどう分配するか」を表す。
実際の設計は「**2種類のアドヘシンを極ごとに分ける**」ものだが、
接合あたりの結合数は同じになる。

- Ag 極（n_Ag 分子）と Nb 極（n_Nb 分子）が接触したときの結合数は
  `min(n_Ag, n_Nb)` で決まる
- Ag と Nb を等量発現させれば n_Ag = n_Nb = N·f_pole/2 となり、
  対称二極（`polar_split = 0.5`）と同じ値になる

したがって**本モデルの鎖の数値はそのまま使える**。変わるのは解釈で、

- Ag 極は Nb 極としか結合できない → **鎖に向きが出る**
- 同種の極どうしは結合しない → 予期しない配置が減る
- 1細胞が2つの接続を持てる → **単極で二量体どまりになる問題は設計で回避されている**

側面接触については、漏れた Ag と Nb が両方とも側面にあるため、
Ag–Nb の組み合わせで結合できる。したがって側面接触の抑制にはならず、
本モデルの側面の見積もりはそのまま適用される。

## モデルの結論をこの設計に当てはめると

| 本モデルの結論 | この設計での意味 |
|---|---|
| 鎖には両極に集める必要がある | **PopZ + DivIVA の二極化（実験③）が本質的**。ここが失敗すると鎖にならない |
| 極に集めるだけでなく先端に絞る必要がある | 係留機構がどれだけ先端に絞れるかが効く。PopZ の極でのパッチ幅が鍵 |
| 発現量は接合の強さを決め、局在は形を決める | プロモーター強度は「くっつくかどうか」ではなく「どのくらい強くくっつくか」を決める |
| 架橋長を伸ばすと鎖が有利になる | 資料にある **Spacer** がそのまま設計変数になる |

## 架橋長について注意

本モデルの架橋長 2*M* = 8 nm は Costan et al. (2024) の
**ナノボディ–抗原ペア**についての実測値である。この設計の菌体外の接着部も
Ag/Nb なので、この値がそのまま使える。

一方、**ペリプラズム側の CoilR–CoilE の距離は別の量**であり、本モデルは扱っていない。
そちらは資料の連携方針①（MD シミュレーション、担当: ゆう）が
「Coil 同士の結合可能距離」として求めることになっている。
**2つの「距離」を混同しないこと。**

| 距離 | どこ | 何が決めるか | 誰が求めるか |
|---|---|---|---|
| 2*M* = 8 nm | 菌体外（細胞間） | Ag–Nb ペアの長さ | 本モデル（Costan の実測値） |
| CoilR–CoilE 間 | ペリプラズム（細胞内） | コイルドコイルの結合距離 | 連携方針① の MD |

## 本モデルが answered した問いと、まだ open な問い

**answered**

- 一様分布では束になる（極-極 8 対に対し側面 100 対）
- 鎖には両極が必要（片極だけでは二量体で止まる）
- 極に集めるだけでは足りず、先端に絞る必要がある
- 発現量では形は変わらない
- 震盪培養のせん断は接合を壊さない

**open（本モデルの外）**

- 係留機構が実際にどれだけ先端に絞れるか（= `tip_width_um` の実測値）
- PopZ 極と DivIVA 極に、それぞれ何分子の Intimin を係留できるか
- 外膜タンパクの島構造（直径 0.5 µm）が係留にどう影響するか（仮定 A11）

最後の点は係留機構によって様相が変わる。島の中に閉じ込められた拡散に頼るのではなく、
**内膜側のアンカーが外膜タンパクを直接引き留める**ので、島の制約を回避できる
可能性がある。ただしこれは推測であり、実験①〜⑥がその答えを出すことになる。
