# 原著の導出との照合

Costan et al. (2024) の Supplemental Note に、接触面積 *A*con の導出が式の形で
載っている。本モデルは同じ量を独立に導出しているので、**出力の一致だけでなく
式そのものを突き合わせられる**。その結果をここに記録する。

（原著の記法では *M* が結合長の半分で、2*M* = 8 nm が2細胞をまたぐ全長にあたる。）

## 端 - 端接触：式が完全に一致する

| | 式 | 値 |
|---|---|---:|
| 原著 (S32) | *A*ee = 2π*rM* | 0.01005 µm² |
| 本モデル | patch = π(2*M*)*r* | 0.01005 µm² |

2π*rM* と π(2*M*)*r* は**恒等的に同じ式**である。原著がこの配置について厳密な
面積計算を行っており、本モデルの接触パッチの導出（隙間 *h* ≈ *x*²/*r* が 2*M* に
達する半径 √(2*Mr*) の円盤）はそれと完全に一致した。

**この一致は較正の結果ではない。** 本モデルは原著の式を参照せず、細胞形状から
独立に導出している。同じ量が二つの独立な経路から出たことになる。

## 平行（横並び）接触：隙間の扱いが異なる

| | 式・方法 | 値 |
|---|---|---:|
| 原著 (S40) | *A*par = *rL*·arccos((*r* − 2*M*)/*r*) | 0.165 µm²（論文の記載値） |
| 本モデル | strip = 2√(2*Mr*)·*L* | 0.1131 µm² |
| 厳密な円筒幾何 | 2*r*(1 − cos θ) = 2*M* → 半幅 *r*θ | 0.1132 µm² |

平行に接する2本の円柱では、接触線から角度 θ の位置で各表面が *r*(1 − cos θ) だけ
離れるので、**隙間の合計は 2*r*(1 − cos θ)** になる。これが架橋長 2*M* に等しく
なる θ から半幅を求めると 0.0566 µm、面積は 0.1132 µm² となり、**本モデルの
解析式と一致する**（放物線近似 √(2*Mr*) は、この範囲では厳密解と数値的に同じ）。

一方、原著の式にある arccos((*r* − 2*M*)/*r*) は *r*(1 − cos θ) = 2*M*、すなわち
**隙間の合計 4*M* を許す**条件に対応する。端 - 端の (S32) が 2*M* を使っている
のに対し、こちらは倍の隙間を許していることになり、両者の間で整合していない。

なお、抽出した式をそのまま計算すると 0.0801 µm² となり、原著自身の記載値
0.165 µm² とも一致しない（係数 2 が抜けている可能性が高い。2*rL*·arccos(…) なら
0.160 µm² で記載値にほぼ一致する）。PDF から数式を抽出しているため、
**この読み取りには不確かさがある**。原著の図 S9 を直接確認するのが確実である。

## 直交・斜め接触：原著は 2D 投影の近似

原著はこれらの配置について、次のように明記している。

> this assumed shape is a rhombus instead of the actual shape, and the surface is
> not wrapped over cell cylinder, instead a 2D projection is used

すなわち**菱形の 2D 投影**であり、曲面に沿った面積ではない。本モデルは表面を
等面積の求積点で覆って直接数え上げているため、値が小さく出る。

| | 直交接触 |
|---|---:|
| 原著 (S36) *A*per = 4π*M*(*r* − *M*) | 0.0199 µm² |
| 本モデル（曲面上で数え上げ） | 0.0143 µm² |

## まとめ

| 配置 | 原著 *Â*con | 本モデル | 比 | 備考 |
|---|---:|---:|---:|---|
| 端 - 端 | 0.002 | 0.0023 | 1.13× | **式が同一** |
| 直交 | 0.005 | 0.0032 | 0.63× | 原著は 2D 投影近似 |
| 平行 | 0.036 | 0.0273 | 0.76× | 隙間の扱いが異なる |
| 無秩序平均 | 0.008 | — | — | 原著 (S43) |

**原著が厳密に計算した配置では式レベルで一致し、原著が自ら近似と断っている配置では
本モデルのほうが小さい値を返す。**本モデルは全配置で同一の基準（表面間の隙間が
2*M* 以内、かつ法線が向き合う）を使っており、配置間で整合している。

この差は結論には影響しない。鎖か束かの判定は極接触と側面接触の**比**で決まり、
本モデルではその比が 11.3、原著の値を使えば 16 となって、どちらでも
「局在させなければ束になる」という結論は変わらない。

## 検証の位置づけ

上の照合は `tests/test_source_comparison.py` にテストとして固定してある。
本モデルの端 - 端接触の面積が原著の式 2π*rM* と一致しなくなれば、テストが失敗する。
