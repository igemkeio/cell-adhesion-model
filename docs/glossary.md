# 用語集

このモデルで使う用語の定義。数値は既定条件（細胞長 1.80 µm、細胞半径 0.40 µm、
架橋長 8 nm）での値である。

> 記号は本文・図中の表記、コード名は実装での識別子を指す。

---

## 1. 細胞の形状

### スフェロシリンダー
円柱の両端に半球をつけた形。大腸菌の形状近似として使う。
全表面積は 4.524 µm²。

- コード名: `spherocylinder_surface()`

### 細胞長 *l*
スフェロシリンダーの端から端までの全長。半球部分も含む。

- 記号 `l` ／ コード名 `CELL_LENGTH`, `CELL_LENGTH_UM`
- 値: **1.80 ± 0.25 µm**（実測値）

### 細胞半径 *r*
円柱部の半径であり、両端の半球の半径でもある。

- 記号 `r` ／ コード名 `CELL_RADIUS`, `CELL_RADIUS_UM`
- 値: **0.40 ± 0.10 µm**（実測値）

### 極領域（極、キャップ）
両端の半球部分。「極に局在させる」というときの極はこの領域を指す。
全表面積の **44.4 %** を占める。

- コード名 `regions == -1`（左）, `regions == +1`（右）
- 面積: 4π*r*² = 2.011 µm²

### 円柱部（側面）
極領域を除いた、細胞の胴体にあたる筒状の部分。長さは *l* − 2*r* = 1.0 µm。
全表面積の 55.6 %。

- コード名 `regions == 0`
- 面積: 2.513 µm²

### 測地距離
極の先端から表面に沿って測った距離。まっすぐの直線距離ではなく、
球面上を這った距離を指す。極半球の縁（赤道）までで π*r*/2 = **0.628 µm**。

- コード名 `tip_distances`
- 先端集中度を定義する座標として使う

## 2. アドヘシンと結合

### アドヘシン
細胞表面に提示する接着分子。本系では intimin を足場としてナノボディまたは
抗原を融合したもの。相手の細胞のアドヘシンと1対1で結合する。

### 発現量 *N*
細胞あたりのアドヘシン分子数。**自由パラメータ①**であり、
aTc（誘導剤）濃度で実験的に制御できる。

- コード名 `n_total`
- 値: **7,300 ± 1,800**（100 ng/mL aTc）／ **15,300 ± 4,100**（300 ng/mL、飽和）

### 架橋長 2*M*
アドヘシン対が橋渡しできる距離。**片方の細胞表面から、ナノボディと抗原の両方を経て、
相手の細胞表面まで**の全長を指す。2細胞をまたぐ総額なので、両細胞ぶんを足してはいけない。

- 記号 `2M` ／ コード名 `BRIDGE_LENGTH`, `BRIDGE_UM`
- 値: **8 nm**（実測値）
- 2細胞の表面間距離がこれ以内なら結合しうる、という判定に使う

### 機能割合 *f*p
幾何的に接触可能なアドヘシンのうち、実際に結合を形成する割合。
向きが合わない、既に別の相手と結合している、といった理由で全部は結合しない。

- 記号 `f_p` ／ コード名 `FUNCTIONAL_FRACTION`
- 値: **0.5**（原著の式から逆算して 0.30–0.65 の中央付近）
- 極接触と側面接触の双方に同じ係数がかかるため、**鎖か束かの判定には影響しない**

### 破断力 *F*b
アドヘシン結合1本を引きちぎるのに必要な力。光ピンセットで測定されており、
荷重速度 5–100 pN/s の範囲で値が変わらない。

- 記号 `F_b` ／ コード名 `RUPTURE_FORCE`, `RUPTURE_FORCE_PN`
- 値: **16.1 ± 0.4 pN**（実測値）

### 結合数
2細胞間で実際に成立するアドヘシン結合の本数。
**自由パラメータではなく、接触面積と発現量から決まる従属量。**

- コード名 `bonds_side_by_side`, `bonds_heavy_pole`, `bonds_light_pole`
- 計算: 接触可能な分子数 × *f*p

### 接合強度
1つの接合部が耐えられる力の合計。

- コード名 `junction_force_pn`
- 計算: **結合数 × 16.1 pN**

### 面密度
単位面積あたりのアドヘシン数。局在が物理的に可能かを、外膜のタンパク収容量
（全種合計で 10⁵ /µm² のオーダー）と比較して判断するために使う。

- コード名 `peak_density_per_um2`
- 一様分布・飽和誘導で **3,400 ± 1,200 /µm²**（実測値）

## 3. 局在 — 設計で変えたい量（自由パラメータ②）

局在は3つの数で表す。この3つが多細胞構造を決める。

### 極局在比 *f*pole
全アドヘシンのうち、両極（半球部）に置かれる割合。

- コード名 `f_pole`
- **0.444 が一様分布**（極領域の面積比そのもの）。コード名 `UNIFORM_F_POLE`
- これより大きければ極に濃縮、小さければ側面に偏っていることを意味する
- 実測値は一様（極と中央で有意差なし、p = 0.56）

> **注意**: *f*pole = 0 が「局在なし」ではない。**0.444 が局在なし**である。
> 0.6 や 0.8 は「やや濃縮」程度にすぎない。

### 先端集中度 *w*
極の中で、先端にどれだけ絞って集めるかを表す幅。極先端からの**測地距離**に対する
ガウス分布の標準偏差として定義する。

- コード名 `tip_width_um`
- `None` なら極半球全体に一様（絞り込みなし）
- 極半球の測地距離は最大 0.628 µm なので、*w* = 0.6 程度で「絞り込みなし」に漸近する
- **接触パッチ内の分子数は *w*⁻² で増える**ため、局在パラメータの中で最も効く

### 両極分配（polar split）
極アドヘシンを左右の極にどう配るか。

- コード名 `polar_split`（0.5 – 1.0 で指定）
- **0.5 = 対称二極**（両極に同数）
- **1.0 = 単極**（片方の極に全部、もう片方はゼロ）
- 鎖になるか二量体で止まるかを決める

### 濃い極 / 薄い側の極
両極分配が対称でないとき、アドヘシンが多い側と少ない側の極。

- コード名 `bonds_heavy_pole` / `bonds_light_pole`
- 鎖が伸びるには1細胞が2つの接続を要するので、**律速は薄い側の極**
- 薄い側の極で結合ができなければ、そこで組み立てが止まる

## 4. 接触の幾何

### 接触パッチ
**極どうしが接触したときに、実際に結合を作れる領域。**

曲面どうしは数学的には1点で触れるだけだが、アドヘシンは 8 nm の隙間まで架橋できる。
そのため接触点のまわりの小さな円盤が有効な範囲になる。

半径 *r*c の位置での隙間は *h* ≈ *r*²/*R* なので、*h* = 2*M* となる半径が縁になる。

```
r_c = √(2M · r) = √(0.008 × 0.40) = 0.0566 µm = 56.6 nm
面積 = π · 2M · r = 0.0101 µm²
```

- コード名 `contact_patch_area()`
- **全表面積のわずか 0.22 %**
- 面積は架橋長 2*M* に**比例**する

> 半径が架橋長（8 nm）と細胞半径（400 nm）の**幾何平均**になっている点に注意。
> 架橋長は短いが、細胞が太いおかげで接触面が平らに近くなり、パッチは 56.6 nm まで広がる。

### 接触ストリップ（接触帯）
**側面どうしが平行に接触したときに結合を作れる領域。**

平行な円柱どうしでは軸方向に隙間が広がらないため、円柱部の全長にわたって
帯状に接触できる。

```
幅 = 2√(2M · r) = 113 nm、長さ = l − 2r = 1.0 µm
面積 = 2√(2M · r) (l − 2r) = 0.1131 µm²
```

- コード名 `contact_strip_area()`
- 全表面積の **2.50 %**、接触パッチの **11.3 倍**
- 面積は架橋長の**平方根**に比例する（パッチは比例。ここが両者の非対称性）

### 接触面積割合 *A*con
接触領域が細胞の全表面積に占める割合。原著が配置ごとの経験値として報告している量で、
モデルの検証に使う。

- コード名 `contact_area_fraction()`
- モデル **0.0023 – 0.0274** ／ 報告値 **0.002 – 0.036**

### 配置（Pose）
2細胞の相対的な置き方。2つの角度で決まる。

- コード名 `Pose(relative_angle_deg, contact_normal_deg)`
- `relative_angle_deg`: 2細胞の長軸のなす角
- `contact_normal_deg`: 細胞1から見た接触方向（0 なら長軸方向、90 なら垂直）

| 呼び名 | コード名 | 意味 |
|---|---|---|
| 先端-先端 | `POSE_END_TO_END` | 平行に並んで極どうしが触れる。鎖の単位 |
| 平行・横並び | `POSE_SIDE_BY_SIDE` | 平行に並んで側面どうしが触れる。束の単位 |
| 直交 | `POSE_PERPENDICULAR` | 長軸が直交して触れる。接触面積が最小 |

### 対向角
結合が成立するために、両表面の法線が向き合っていなければならない角度の許容範囲。
アドヘシンは膜から外向きに突き出るため、相手を向いていない分子は距離が近くても架橋できない。

- コード名 `FACING_ANGLE_DEG`
- 値: **60°**（この範囲で向き合っていれば結合可能とみなす）

## 5. 予測される多細胞構造

`Morphology` として返される4つの状態。

| 呼び名 | コード名 | 条件 | 意味 |
|---|---|---|---|
| **鎖** | `CHAIN` | 極接触が優勢、かつ薄い側の極も使える | 一列に伸びる |
| **束** | `BUNDLE` | 側面接触が極接触以上 | 横に固まる |
| **二量体どまり** | `DIMER` | 極接触が優勢だが薄い側の極が空 | 2細胞で止まる |
| **接着しない** | `NO_ADHESION` | どの配置でも結合が1本未満 | 発現量が足りない |

### 形態の閾値
鎖が束に打ち勝つのに必要な極局在比。**発現量に依存しない**（極接触も側面接触も
発現量に比例するため、比を取ると消える）。

- コード名 `morphology_threshold()`

| 先端集中度 *w* | 必要な *f*pole |
|---|---:|
| 集中なし | 事実上達成不能 |
| 0.30 µm | > 0.819 |
| 0.20 µm | > 0.679 |
| 0.10 µm | > 0.444 |

## 6. 震盪培養と力学

### せん断速度 γ̇
流体中の速度勾配。細胞を出会わせ、また接合を引っ張る。

- コード名 `shear_rate()`
- γ̇ = √(ε/ν)。フラスコ震盪の典型値で **100 – 1000 s⁻¹**

### 散逸率 ε
単位質量あたりに流体へ投入される仕事率。震盪の激しさを表す。

- 値: フラスコ震盪で **0.01 – 1 W/kg**

### コルモゴロフ長
乱流の最小渦のスケール。これが細胞より十分大きければ、細胞は渦の内側にいて
一様なせん断を受ける（乱流ではなく層流せん断とみなせる）。

- コード名 `kolmogorov_length_um()`
- 値: **32 – 100 µm**。細胞（1.8 µm）よりはるかに大きい

### 鎖の張力
せん断中の細胞鎖の中央にかかる引張力。**鎖長の2乗**で効くため、長い鎖ほど不利。

- コード名 `chain_tension_pn()`
- γ̇ = 300 s⁻¹、10 細胞の鎖で **12.3 pN**

### 衝突頻度
細胞どうしがぶつかる頻度。震盪の主な役割はこれを増やすことにある。

- コード名 `collision_rate_per_s()`（せん断による）、
  `brownian_collision_rate_per_s()`（ブラウン運動による）
- せん断による衝突はブラウン運動の **27 – 267 倍**

### orthokinetic / perikinetic
凝集理論での用語。**orthokinetic** は流れ（せん断）による衝突、
**perikinetic** はブラウン運動による衝突を指す。

## 7. 生物学的な背景

### 外膜
グラム陰性菌が持つ最外層の膜。アドヘシンはここに提示される。
内膜との間にペリプラズムを挟む。

### Oアンチゲン
外膜を覆うリポ多糖（LPS）の最外部にある繰り返し糖鎖。膜から 10–30 nm 以上伸びる。
**アドヘシンの前に立ちはだかる立体障害**になりうるが、K-12 誘導体（MG1655、DH5α など）
と BL21 はこれを持たず、コア糖鎖のみ（3–6 nm）なので 8 nm の架橋で越えられる。

### 古い極 / 新しい極
細胞分裂のたびに、各細胞は分裂面由来の「新しい極」と、前世代から引き継いだ
「古い極」を1つずつ持つ。外膜タンパクは分裂面付近で挿入され、成長とともに
古い島が極へ押しやられるため、**古い極に蓄積する**。

この偏りは**単極型**であり、対称二極ではない。したがって放置して自然に出てくる
局在では鎖にならず、二量体で止まる。

### aTc 誘導
アンヒドロテトラサイクリンによる発現誘導。原著が濃度と分子数の対応を実測しており、
本モデルの発現量パラメータはこれに紐づく。
