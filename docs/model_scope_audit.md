# モデルは設計資料に沿っているか — 監査

「One Direction」（iGEM Keio-Japan 2026）の設計資料と、本モデルの実装を
一つずつ突き合わせた結果。

本モデルが担当するのは資料の **DryとWetの連携方針② の 2**：

> **Intimin の局在パターンから細胞間の結合様式予測**
> 手法：Intimin を配置した複数の細胞モデルを用い、**多価結合とブラウン運動を
> 考慮した**シミュレーション
> 知りたいこと：Intimin の数や局在の仕方によって、**細胞がどの向きで結合するか**、
> あるいは結合しないか。
> Wet への貢献：**方向性のある接着**が起こりやすい発現量・局在条件を絞り込む。
> Wet 実験で最後までできない、**方向性接着の様子を可視化**できる。

## 一致している点

| 項目 | 状況 |
|---|---|
| 接着分子の系 | Intimin + Ag/Nb。Costan et al. (2024) と Glass & Riedel-Kruse (2018) は資料が引用している当の文献であり、**同一の系** |
| 細胞の形状 | 大腸菌をスフェロシリンダーで近似。資料の二極化モデルも「円柱＋半球で近似」としており一致 |
| 多価結合 | 接触面内の分子を数え上げ、結合数 × 破断力で接合強度を出している |
| 「あるいは結合しないか」 | `NO_ADHESION` として出力する |
| 局在パターン → 結合様式 | これが本モデルの中心。局在（`f_pole`, `tip_width_um`, `polar_split`）を入力に、形態を出力する |
| 発現量・局在条件の絞り込み | 形態マップがこれを与える |

## ずれている点

### 1. 方向性が出力に入っていない（最重要）

資料で「方向」は 21 回現れる。プロジェクト名そのものである。しかし本モデルの
出力は `NO_ADHESION` / `BUNDLE` / `DIMER` / `CHAIN` の4つで、
**鎖に向きがあるかどうかを区別していない。**

設計では Ag 極と Nb 極が別なので、Ag 極は Nb 極としか結合できず、鎖は
頭-尾で揃う。本モデルはこの制約を表現しておらず、「1種類のアドヘシンを
両極に分配する」という別のモデルになっている。

**数値としての結合数は同じになる**（Ag と Nb を等量発現させれば
`min(n_Ag, n_Nb) = N·f_pole/2` で対称二極と一致する）が、
**「どの向きで結合するか」という問いには答えていない。**

### 2. ブラウン運動が入っていない

資料は手法として「多価結合と**ブラウン運動**を考慮したシミュレーション」を
挙げている。本モデルは仮定 A7 で時間・速度論・ブラウン運動を明示的に除外しており、
**この点で資料の指定と食い違う。**

本モデルは「接触した2細胞がどの配置を取るか」という相対的な有利不利しか
答えられない。衝突から接着に至る過程、方向が揃うまでの時間、
できあがった鎖の長さ分布は扱えない。

なお `iGEM-MD/demo_ellipsoid/binding/multivalent_dynamics_2d.py` には
ブラウン動力学の実装があった。本リポジトリはそれを引き継いでいない。

### 3. 「方向性接着の様子を可視化」ができていない

資料は Wet への貢献として「Wet 実験で最後までできない、方向性接着の様子を
**可視化**できる」ことを挙げている。本モデルが出すのは形態マップと相図であり、
**細胞が実際に繋がっていく様子は描けない。** これは 2 と同じ理由による。

### 4. 架橋長が改変前の Intimin の値

本モデルの 2*M* = 8 nm は Costan et al. の構築についての実測値である。
一方この設計の Intimin は、

- **LysM を除去**して **CoilE を付与**
- passenger の前に **Spacer** を持つ

という改変を受けている。**Spacer の分だけ菌体外の到達距離は伸びるはずで、
8 nm がそのまま当てはまるとは限らない。**

これは軽い問題ではない。本モデルによれば極接触の面積は 2*M* に比例するので、
架橋長が変われば結合数が直接その比で変わる。

### 5. 誘導系が違う

本モデルは発現量を aTc 濃度に紐づけている（Costan et al. の実測）。
しかし資料に aTc は **1回も出てこない**。出てくるのは **IPTG**（PopZ の誘導）と
「プロモーター強度」である。

したがって本モデルの発現量の軸は、**そのままでは Wet の操作量に対応しない。**
プロモーター強度から分子数への対応づけが別に必要になる。

### 6. 局在を機構から導いていない

本モデルは局在を**入力として受け取る**。実際にはそれは
PopZ → H3H4 → TM → CoilR ‖ CoilE → Intimin という係留機構の結果として決まる。

資料では連携方針②の **1**（担当: じく）が「発現量から Intimin の局在パターン予測」を
担当することになっている。**本モデルはその出力を受け取る側**であり、
両者の接続は次のようになるべきである。

```
じくのモデル                        本モデル
発現量・プロモーター強度  ──→  f_pole, tip_width_um, polar_split  ──→  結合様式・方向
```

この受け渡しの形式が両者で合意されていない。

### 7. 震盪培養は資料にない

本モデルには震盪培養のせん断・衝突頻度の解析が入っているが、これは資料には
現れない。**会話の中で指定された条件**であり、プロジェクトの仕様ではない。
残す価値はあるが、資料由来ではないことを明示しておく。

## 優先順位

| | 項目 | 影響 |
|---|---|---|
| 1 | **方向性を出力に入れる** | プロジェクトの中心概念。これがないと問いに答えていない |
| 2 | **架橋長を Spacer 込みで見直す** | 結合数に直接比例する。値そのものが変わる |
| 3 | **ブラウン運動を入れる** | 資料の指定手法。可視化もこれに依存する |
| 4 | 発現量とプロモーター強度の対応 | Wet の操作量と繋がらないと使いにくい |
| 5 | じくのモデルとの受け渡し形式を決める | 分担の接続 |

1 は本モデルの枠組みのまま実装できる。2 は Spacer の設計が決まれば値を差し替える
だけである。3 は枠組みの拡張が必要で、仮定 A7 を外すことになる。
