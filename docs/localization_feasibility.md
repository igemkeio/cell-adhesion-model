# 極局在は実現できるか — 文献調査

本モデルの結論は「鎖を作るには**対称二極**に、**極先端 0.20 µm 以内**へアドヘシンを
濃縮する必要がある」というものだった。これが生物学的に達成できるのかを調べた。

> **注意** 以下は検索結果の要約に基づく一次調査であり、各論文の全文照合は行っていない。
> 設計判断に使う前に、リンク先を確認すること。

## 結論

| 問い | 答え |
|---|---|
| 外膜タンパクの極局在に前例はあるか | **ある**（Shigella IcsA） |
| その局在配列は他のタンパクに移植できるか | **できる**（2箇所が各々独立に十分） |
| それは**対称二極**か | **いいえ。単極（old pole）** |
| 両極の外膜提示に前例はあるか | **見つからなかった** |
| 極局在は外膜タンパク一般の性質か | **いいえ。IcsA 特異的** |
| Intimin 自体は極局在するか | **しない。一様分布** |

**本モデルの予測に照らすと、既知の手段で到達できるのは単極局在であり、それは
二量体どまりを意味する。**（`predict(7300, 0.95, polar_split=1.0, tip_width_um=0.10)`
→ 濃い極 529 対、薄い極 0 対、構造は `DIMER`）

## 1. 前例：Shigella IcsA（VirG）

外膜オートトランスポーターで、**細胞の古い極（old pole）に単極局在**する。
アクチンテールを一方向に伸ばすために極性が必要という、明確な生物学的機能を持つ。

分かっている性質：

- **局在配列は転移可能**。アミノ酸 1–104 と 507–620 が、**各々独立に極局在に十分**
  （[J. Bacteriol. 2008](https://journals.asm.org/doi/10.1128/jb.00093-08)）
- **標的化は細胞質側で起こる**。N末端シグナルペプチドに依存せず、外膜挿入より前に
  決まっている（[PubMed 14507362](https://pubmed.ncbi.nlm.nih.gov/14507362/)）
- Sec 装置は膜全体に一様に分布しているのに、IcsA は極に出る
- **プロテアーゼ IcsP** が極からはみ出した IcsA を切って極性を維持する
- **MreB** が極への配置を助ける
  （[J. Cell Sci. 2019](https://journals.biologists.com/jcs/article/132/9/jcs226217/140/)）
- 異種タンパク（Bla、MalE）の**表面提示ベクターとして使われた実績がある**
  （[Microb. Cell Fact. 2012](https://microbialcellfactories.biomedcentral.com/articles/10.1186/1475-2859-11-20)）

## 2. しかし単極である

IcsA は **old pole に一つ**の局在で、対称二極ではない。本モデルでは、

- 単極 → 1細胞が持てる接続は1つ → **二量体で組み立てが止まる**
- 接合そのものは対称二極より**2倍強くなる**（分子が片極に集中するため）

つまり IcsA の機構をそのまま借りても、**強い二量体**は作れるが**鎖**にはならない。

これは Rassam et al. (2015) が示した外膜の空間構造とも整合する。外膜タンパクの
生合成は分裂面付近で最も高く極ではほぼ起きず、古いタンパクが古い極へ押しやられる。
**外膜で自然に生じる極性は本質的に単極である。**

## 3. 極局在は外膜タンパク一般の性質ではない

別のオートトランスポーター SepA の α ドメインを GFP に融合しても、蛍光は
**拡散した分布**になった。極局在は IcsA に特異的な性質であり、外膜に出せば
極に行くというものではない。

## 4. Intimin 自体は一様分布

EPEC の免疫標識で、**intimin は菌体表面に一様に分布する**と報告されている
（[PNAS 2000](https://www.pnas.org/doi/10.1073/pnas.97.16.8799) 系の記述）。

これは Costan et al. (2024) が合成アドヘシンについて測った結果（極と中央で
有意差なし、t検定 p = 0.56）と**独立に一致する**。本モデルの基準点（仮定 A10）が
二つの独立な経路から支持されたことになる。

## 5. 鎖を作る別の経路：娘細胞の分離を止める

天然の鎖形成菌が使っている機構は、接着分子ではなく**細胞分裂後の分離の抑制**である。

大腸菌では3つのペプチドグリカンアミダーゼ **AmiA / AmiB / AmiC** が隔壁の
ペプチドグリカンを切って娘細胞を分離する。活性化因子は **EnvC**（内膜側、FtsEX に結合）
と **NlpD / ActS**（外膜リポタンパク）である。

**これらを欠損させると、娘細胞が分離せず長い鎖状に連なる。**
（[PMC1951850](https://ncbi.nlm.nih.gov/pmc/articles/PMC1951850)、
[PLOS Genet. 2025](https://journals.plos.org/plosgenetics/article?id=10.1371%2Fjournal.pgen.1011626)）

この経路の性質：

| | 極局在アドヘシン | アミダーゼ欠損 |
|---|---|---|
| 鎖ができるか | 対称二極が必要（未達成） | **できる** |
| 接続の強さ | 結合数 × 16.1 pN | **ペプチドグリカン連続**（桁違いに強い） |
| どの細胞が繋がるか | **設計できる** | 分裂の履歴で決まる |
| 異種細胞を混ぜられるか | **できる** | できない |
| 外部信号で制御できるか | **できる**（誘導） | 難しい |

**鎖という形だけが目的ならアミダーゼ欠損のほうが確実である。**一方、
「どの細胞とどの細胞が、いつ繋がるかをプログラムする」ことが目的なら、
アミダーゼ欠損はそれを与えない。**どちらが目的なのかで選ぶべき手段が変わる。**

## 6. 設計の選択肢

本モデルと本調査から、取りうる道は次のようになる。

**A. 単極アドヘシン（IcsA 型）で二量体を作る**
既知の手段で到達可能。1細胞1接続なので鎖にはならないが、接合は強い。
「2種類の細胞を1対1で確実にペアにする」ことが目的なら、これで足りる。

**B. アミダーゼ欠損で鎖を作り、アドヘシンは別の役割に使う**
鎖の骨格は分裂由来の連続性で作り、アドヘシンは鎖どうしの結合や
標的への接着など、プログラム可能性が要る部分に回す。

**C. 対称二極局在を新規に開発する**
前例がなく、かつ島構造（直径 0.5 µm）より細かく絞る必要がある（仮定 A11）。
**難度が高い。**挑戦するなら、まず「両極に出せるか」を Yes/No で確かめる
実験を先に置くべきで、モデルの精緻化を先行させても意味がない。

**D. 幾何の要求そのものを緩める**
本モデルによれば、極接触の面積は架橋長 2*M* に比例し、側面接触は √(2*M*) に
比例する。**リンカーを長くすると鎖が相対的に有利になる。**
原著も設計指針として「longer linkers」を挙げている。局在を絞る代わりに
架橋長を伸ばす方向は、まだ検討していない。

## 7. モデル側で次にやるなら

選択肢 D は本モデルで**すぐ評価できる**。`BRIDGE_LENGTH` を変えて
`morphology_threshold()` を引き直せば、「架橋長をどこまで伸ばせば、
達成可能な局在（たとえば *w* = 0.5 µm、島1個ぶん）で鎖になるか」が出る。

これは局在を絞れないという制約を、分子設計で回避できるかという問いにあたる。
実際に計算した結果が下である。

### 架橋長を伸ばすと必要な局在はどこまで緩むか

局在を島1個ぶん（*w* = 0.5 µm、先端集中なしに近い）に固定し、架橋長だけを変えた。

| 架橋長 2*M* | 鎖に必要な *f*pole |
|---:|---:|
| 8 nm（現状） | > 0.925 |
| 16 nm | > 0.900 |
| 24 nm | > 0.881 |
| 32 nm | > 0.869 |
| 48 nm | > 0.848 |

**効くが、弱い。** 極接触の面積は 2*M* に比例、側面接触は √(2*M*) に比例するので、
比の改善は √(2*M*) にとどまる。架橋長を6倍にしても、必要な *f*pole は
0.925 から 0.848 にしか下がらない。

とはいえ意味はある。**サブ島スケールの集中（*w* ≤ 0.20 µm、おそらく不可能）を
要求する代わりに、「島スケールの局在 + 極への 85 % 濃縮 + 50 nm 程度のリンカー」
という組み合わせでも鎖の条件を満たせる。** 後者のほうが、少なくとも各要素は
個別には現実的である（ただし**対称二極**であることは依然として前例がない）。

### モデルの適用限界

この計算には上限がある。架橋長を大きくすると接触パッチの半径 √(2*M*·*r*) が
極半球の測地距離（0.628 µm）に近づき、**「極」と「側面」の区別自体が意味を失う**。

| 2*M* | パッチ半径 | *f*pole=0.999 での極接触 / 側面接触 |
|---:|---:|---|
| 8 nm | 57 nm | 37 / 37 |
| 32 nm | 113 nm | 152 / 152 |
| 64 nm | 160 nm | 315 / 314 |
| 128 nm | 226 nm | 635 / 637 |

極に全分子を置いても両者がほぼ同数になる。これは横並び配置でも極の分子が
拾われるためで、この領域では本モデルの判定は数値的な同着になり信頼できない。

**したがって上表は 2*M* ≲ 50 nm の範囲でのみ意味を持つ。**
それ以上の架橋長を検討するなら、極と側面を面積で二分する現在の枠組み自体を
作り直す必要がある。
